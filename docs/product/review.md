# Review — the debt register and the review log

**The living record of known problems, and what each review actually checked.**

**The METHOD is not here.** The four lenses, how to run a review, how findings become work, and the
review anti-patterns all live in [review-method.md](review-method.md) — read that before running a
review, and this file when you need to know whether something is a gap or a deferral. They were one
file until 2026-07-30, when it reached 65 KB: a stable method wrapped around a register that changes
every session.

Why the register exists: in a codebase edited by sessions with no shared memory, drift is the
default. Each session makes locally reasonable choices; nothing accumulates a view of whether the
whole still matches its design. Nobody notices that the fourth repository function quietly omitted
the space filter, or that a domain doc has described a non-existent column for two milestones.

**Section numbers are unchanged** — the register is still §3 and the log still §6, so every existing
`#3-debt-register` link resolves. §1, §2, §4 and §5 moved to
[review-method.md](review-method.md) and kept their numbers there. Do not renumber either file.

**Ordered by id, ascending — not chronologically.** It used to be roughly chronological and had drifted
(`D37, D42, D43, D41, D40, D39, D38, D42, D43, D44…`), which is how **two pairs of rows came to share an
